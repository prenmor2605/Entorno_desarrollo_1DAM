
# Github y Copilot
## Github

**_GitHub_** es una plataforma para alojar _código, controlar versiones y colaborar en proyectos de software_. Utiliza Git para gestionar los cambios del código.

**_Microsoft_** es la empresa propietaria de GitHub desde 2018, cuando adquirió la plataforma por aproximadamente 7.500 millones de dólares.

## **GitHub Copilot**
**GitHub Copilot** es un asistente de inteligencia artificial que ayuda a los desarrolladores a:
- Generar código.
- Completar código automáticamente.
- Explicar código.
- Detectar y solucionar errores.
- Crear pruebas.
